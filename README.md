# 🛰️ Defence Surveillance Simulator

A Python-based academic simulation project for demonstrating radar visualization, simulated target tracking, camera-based object detection, alerts, database logging, statistics, and a web dashboard.

## ⚠️ Academic Project

This is a software-only educational simulation.

It does not provide real-world weapon guidance, targeting, interception, or military control functionality.

## 🚀 Features

- 🛰️ Simulated Radar
- 🎯 Target Tracking
- 🚨 Alert System
- 📷 OpenCV Camera Detection
- 🗄️ SQLite Database
- 📊 Statistics
- 📜 Detection History
- 📥 CSV Report Export
- 🔐 Demo Login
- ℹ️ About Project Page
- 🌐 Flask Web Dashboard

## 🛠️ Technologies

- Python
- Flask
- OpenCV
- NumPy
- SQLite
- HTML
- CSS
- JavaScript
