Defence Surveillance Simulator

A software-based academic project that demonstrates simulated radar monitoring, object tracking, camera-based motion detection, alert management, database logging and report generation through a web dashboard.

📡 Simulated Radar

Displays synthetic targets on an animated radar interface and demonstrates continuous target monitoring.

🎯 Object Tracking

Maintains simulated target information such as distance, speed, angle and monitoring status.

📹 Camera Detection

Uses OpenCV background subtraction to demonstrate motion-based object detection from a connected camera.

🚨 Alert Management

Generates visual alerts when simulated target conditions cross the configured demonstration threshold.

🗄️ Database

SQLite stores simulated detection records including distance, speed, angle, status and timestamp.

📥 Report Generation

Detection history can be exported as a CSV report for analysis and project demonstration.
